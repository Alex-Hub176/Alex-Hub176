## 🛡️ Detector de Phishing URL

Aplicação de linha de comando desenvolvida em Python para analisar URLs e identificar características que podem indicar uma tentativa de phishing.

O projeto utiliza diferentes verificações para analisar características suspeitas de uma URL e gerar uma pontuação de risco.

**Tecnologias e conceitos:**

* 🐍 Python
* 🔎 Análise de URLs
* 🛡️ Conceitos básicos de segurança
* 🧠 Lógica de programação
* 💻 Aplicação CLI

> Projeto em evolução. Pretendo futuramente melhorar sua estrutura e aplicar conceitos de Programação Orientada a Objetos e arquitetura de software conforme avanço nos estudos.

🔗 **[Ver projeto no GitHub](https://github.com/Alex-Hub176/detector-phishing-url)**
